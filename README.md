# Tahoe
Tahoe is a foray into Large Language Model (LLM) autoregressive pretraining. The provided code focuses on clarity rather than efficiency, and is mostly for self-learning purposes :) 

This repo largely follows Stanford's cs336 course, though with some minor deviations.

## Data
Tahoe models are trained on two datasets: TinyStories v2 (TSv2) and a sampled version of OpenWebText (OWT). Both of these datasets may be downloaded via `./download_data.sh`.
